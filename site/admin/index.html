DSA Sheet Admin

Manage Topic Unlocks

Use your admin token to inspect licenses, manually confirm payments, and reset a learner’s machine when they change devices.

Admin Session

Enter the backend base URL and admin bearer token once. The token stays in this browser only.

License Lookup

Search all licenses issued for an email. This is the fastest support flow when a user says their topic did not unlock.

Machine Reset

Use this after a laptop change or OS reinstall. If you leave Code ID empty, the latest active license for that email is reset.

Manual Payment Confirm

For manual UPI or operator-assisted payments, confirm the payment here and the backend will issue the unlock code immediately.
